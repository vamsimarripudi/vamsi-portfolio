# GSAP

GSAP 3.15.0 is installed from the official npm package at an exact version. Original distribution headers, copyright and license references are preserved.

Source: https://gsap.com/
License: https://gsap.com/standard-license/

The Corner endpoint serves only the exact installed gsap.min.js distribution; no other node_modules files are exposed. The React build includes GSAP as a local, lazy-loaded chunk.
