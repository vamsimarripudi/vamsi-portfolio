The source of the PakkaFollow logo is the actual product repository `vamsimarripudi/pakkafollow` at `web/public/icon.svg` on `main` (Git blob SHA `9c1d6946ce11c93032e1e77e95d09b40228e4e2a`). That SVG is referenced by the product site's HTML and installable-app manifest, and matches its approved forest-green / cream “p.” identity.

The portfolio owns a **byte-for-byte copy** at `public/brand/pakkafollow-icon.svg`; do not regenerate, trace or recolor it. It is shown beside the product name in the homepage focus card, homepage selected Work, the Work listing, and the PakkaFollow case study. The portfolio's own VM site logo and favicons remain unchanged.

A repository test verifies the original Git blob SHA to detect unintended visual modifications. This is a public branding change only: no company-owned products, app passwords, private repositories' source files (other than the expressly authorized logo), user records, or product claims are exposed. The logo has no automatic deployment implications.
