# Privacy questions and requests process

## Intake

Receive requests at `enquiry.portfolio@vamsimarripudi.tech` with **Privacy request** in the subject. Record the date, request type, contact email, and reference ID if supplied; do not copy more message content than necessary into any tracking note.

## Verify and assess

1. Confirm the requester controls the email address used for the original enquiry, or ask for proportionate evidence where needed.
2. Identify information held in the private Enquiry Tracker, enquiry mailbox, transient service logs where accessible, and any relevant provider account controls.
3. Determine whether correction, deletion, access information, withdrawal, or grievance handling is feasible and whether a lawful, security, or dispute reason requires continued retention.

## Respond

Reply using the requester’s verified contact channel. Explain the action taken, any information that cannot be altered or deleted, and the reason in plain language. Track statutory deadlines only after confirming the applicable DPDP commencement provision and any then-current prescribed procedure.

## Escalation

If the request involves a security incident, law-enforcement demand, identity uncertainty, sensitive data, or a dispute, pause routine processing and obtain appropriate legal or security advice.
