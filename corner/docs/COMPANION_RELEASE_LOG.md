# Corner companion release log

## 3.1 — sweet-20261027

Owner approved implementation, merge and deployment on 27 October 2026. This extends the verified Doraemon branch rather than creating a separate disconnected demo.

### Included
- Articulated Doraemon, distance-driven stride, safe repeated patrol, edge hide/peek/return, first-party story discovery and original opt-in audio from v3.
- Short gentle English greetings and finite high-five, surprised shudder, shy smile, giggle, original jokes and balancing scenes. No emotional profiling or dialogue generated from private input.
- Progressive text reveal with a complete screen-reader equivalent, immediate reduced-motion presentation, tap-to-reveal and Escape dismissal. Bubble and actor placement protect text, controls and the Current status card.
- Optional phone-shake input. Direct-click permission request; real finite readings before reporting active; no-reading timeout; denied/unavailable states; filtered alternating-peak detection and 12-second cooldown. Normal Surprise him button is the equivalent input. Pause/Hide, typing, modal and document lifecycle stop processing. Raw readings never leave the closure and are not retained as history.
- Real recent-story category filters, saved-stories link and left/right/automatic resting preference. Settings remain page-local, with no new cookie or storage inventory.
- Visible release identifier in the controls and read-only snapshot for post-deploy verification.

### Verification and boundaries
Local six-width Chromium tests passed, with simulated sensors for permission/readiness/denial/cooldown/pause. The same behavior is covered in repository CI alongside existing movement, account, Studio, privacy and API gates. Simulated sensor tests are not physical-iPhone verification; speaker loudness remains a real-device acceptance item.

The optional companion ceilings are reviewed at 65 KB JS / 23 KB CSS raw and 21 KB / 6 KB gzip. Core application budgets are unchanged. This is a functioning authored website character, not a conscious agent or chat service. No official Doraemon voice, theme music, license or endorsement is represented.

### Not part of this release
Cross-device preference sync, reading-history memory, a new Studio Companion Director, live tilt balancing and unbounded free-form chat are future scope, not placeholder controls. The balancing trick shipped here is a deliberately started animation. The existing owner status and published posts remain the authoritative content source.

### Improvement procedure
Each future update gets a versioned entry, an isolated interaction recording, regression tests, explicit release authorization and live-version verification. Do not change this into automatic daily deployments. A daily improvement desire does not justify unreviewed production changes.
